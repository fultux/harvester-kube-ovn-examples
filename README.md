# harvester-kube-ovn-examples
Sample configurations for the kube-ovn implementation in Harvester.


## Examples Included

- **External Gateway (`external-gateway/`)**: Demonstrates how to configure an external gateway, including setup for SNAT, DNAT, internal/external subnets, and provider VLANs.
- **NAT Outgoing Subnet (`nat-outgoing-subnet/`)**: Provides configurations for subnets with NAT outgoing enabled.
- **VPC Peering (`vpc-peering/`)**: Contains examples for setting up VPC peering between different VPCs, including subnets and virtual switches.

Each example directory includes architecture diagrams, YAML manifests, and a dedicated README.
